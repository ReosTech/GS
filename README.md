# Reos App

Android web app wrapper for reostech.pagekite.me with native navigation, offline handling, real-time Open-Meteo weather forecasts, modular add-ons & device permissions, and an advanced multimodal AI suite.

## Features
- **Reos Portal**: Fullscreen responsive WebView wrapper connected to live Reos services (`https://t.ly/Zalxp` with automatic fallback to `https://reostech.pagekite.me`).
- **Weather & Meteorological Alerts**: Live GPS / location telemetry, hourly rain radar, 7-day forecast, and Gemini AI weather advisor.
- **Add-ons & Permissions Hub**: Push notifications, location telemetry, camera scanner, and Reos account email access sync.
- **Homescreen Widgets**: Quick launch portal widget and glanceable weather & alerts widget.
- **Advanced AI Suite**: Multimodal generative AI tools including Chatbot, Image Generation, Veo Video Director, and Lyria Music Synthesizer.
